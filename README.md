BREACHLINE is a round-based tactical FPS in the browser: 5v5 bomb-defusal rounds against bots on an original foundry map, with a money economy and buy menu, five weapons, three grenade types, and recoil-driven gunplay where stopping to aim pays. Built on three.js, offline, no build step.

## Run it

```sh
node serve.ts  # then open http://localhost:8080
```
